# Translation Priority Card

**If you only read one line: translate the cards people act on first, using official sources and community review.**

## 1. Translate actions, not theory

**Priority 1.**
- `kids-what-to-do.md`.
- `stop-the-bleed.md`.
- `water-purification.md`.
- Shelter-in-place instructions.
- `summons.md`.

**Keep it operational.**
- Short commands.
- Same section order.
- Same numbers.
- Same source line.
- No local idioms unless the reviewer confirms them.

## 2. Spanish first

**Start where the need is largest.**
- Spanish is the most-spoken non-English language in U.S. homes.
- FEMA, Red Cross, CDC, and many state emergency management offices already publish Spanish emergency material.
- Link to official Spanish material when it exists.
- Translate only the repo-specific action card when no official equivalent exists.

## 3. Use official sources

**Do not machine-translate life-safety content and ship it alone.**
- Use Ready.gov/es.
- Use American Red Cross Spanish pages.
- Use CDC Spanish pages.
- Use state emergency management Spanish pages.
- Use local public-health or fire-department Spanish handouts.

**Keep provenance visible.**
- Source line stays at the bottom.
- Add translator and reviewer names only if they consent.
- Record date reviewed.
- Keep source URLs in a maintainer note if the printable card must stay short.

## 4. Community vetting

**Use two passes.**
- Professional translation or trained bilingual translator first.
- Native-speaker community review second.

**Check the right things.**
- Idiom.
- Register.
- Literacy level.
- Regional dialect.
- Emergency vocabulary.
- Whether the action is clear under stress.

## 5. Pictograms are universal

**Use pictures for actions.**
- Valve off.
- Crawl low.
- Do not drink.
- Meet here.
- Call this number.
- Take this bag.

**Use known symbol systems.**
- ISO 7010 safety signs where they fit.
- FEMA or USFA pictograms where available.
- Simple black-and-white line art for printing.
- Test with someone who does not speak the language.

## 6. Distribute through trusted channels

**Put cards where people already go.**
- Community clinics.
- Churches.
- WIC offices.
- Food banks.
- Tenant associations.
- Community radio.
- Promotoras and community health workers.
- School family-resource centers.

**Do not hide translations in a repo.**
- Print.
- Laminate.
- Hand out.
- Put PDF copies on phones.
- Ask trusted messengers to explain the card once.

## 7. Iteration beats perfection

**Ship the first useful version.**
- Ship a v1 Spanish summons card this month.
- Review with community feedback every 6 months as a rule of thumb.
- Fix confusing words first.
- Keep a changelog for life-safety changes.

**Do not drift from the source.**
- Same actions.
- Same numbers.
- Same warnings.
- Same citations.
- Same print size.

*Source: Ready.gov/es; FEMA language access and public preparedness materials; American Red Cross Spanish emergency preparedness materials; CDC Spanish emergency preparedness and WASH materials; U.S. Census Bureau American Community Survey language-use releases; ISO 7010 safety signs; U.S. Fire Administration pictographs.*
