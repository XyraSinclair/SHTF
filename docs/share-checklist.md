# Sharing checklist

Before posting publicly
- Run `./tools-scripts/get-squared-away.sh`
- Run `./tools-scripts/verify-all.sh --essential`
- Run `./tools-scripts/print-cards.sh`
- Skim `README.md`, `START-HERE.md`, `FIELD-INDEX.md`, and `USAGE.md`
- Confirm the repo is on `main` and clean
- Decide whether to push only the trust-surface polish commit or any later follow-up changes too

Links to include in a post
- repo URL
- `START-HERE.md`
- `README.md`

Suggested framing
- offline emergency reference cabinet
- practical defaults, not doctrine
- playbooks in front, library behind
- optional local AI

Do not lead with
- apocalypse language
- political identity
- lifestyle branding
- claims of comprehensiveness or authority beyond the cited sources
