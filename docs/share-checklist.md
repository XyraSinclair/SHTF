# Sharing checklist

Before posting publicly
- Run `./tools-scripts/build-envelope.sh` and confirm `playbooks/envelope/` builds cleanly
- Run `./tools-scripts/get-squared-away.sh`
- Run `./tools-scripts/verify-all.sh --essential`
- Skim `README.md`, `START-HERE.md`, `playbooks/cards/tonight.md`, `FIELD-INDEX.md`, and `USAGE.md`
- Confirm the repo is on `main` and clean

Links to include in a post
- repo URL
- `START-HERE.md`
- `README.md`
- `playbooks/cards/tonight.md` (the single-page sheet)

Suggested framing
- offline household continuity kit
- one command produces a print-once manila envelope
- playbooks in front, library behind
- optional local AI (Gemma 4, one-command setup)
- practical defaults, not doctrine

Do not lead with
- apocalypse language
- political identity
- lifestyle branding
- claims of comprehensiveness or authority beyond the cited sources
